For learning to recognize kanji.

- Add words to the `entries` file.  
- Run `uv run build_from_entry_list.py` to process entries and update 
    `anki_notes.txt`.  
- Use `index.html`.  

"Again", "Hard", and "Easy" show on average after 10, 30, and 500 cards
respectively. Else, you see "Normal" cards.
