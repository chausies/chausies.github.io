# Minimalist Youtube Clip Linker

Made my own since I couldn't find another <.<

## Example Usage

[chausies.xyz/yt#v=dQw4w9WgXcQ&s=42&e=60](https://chausies.xyz/yt#v=dQw4w9WgXcQ&s=42&e=60)

- Video ID can be designated with `id`, `i`, `v`, `vid`, etc.
- Start Time (optional): `start`, `s`, `st`
- End Time (optional), `end`, `e`, `ed`, `en`

Times can be formatted like  
- `s=69`: starts at 69 second mark    
- `s=4m20s`: starts at 4 minutes 20 second mark  
- `s=3.14`: starts at 3 seconds, 140 milliseconds
